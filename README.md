# UiPath Email Address Extractor

## Overview

This UiPath automation extracts an email address from a text string using built-in string methods.

The workflow demonstrates:

* IndexOf()
* LastIndexOf()
* Substring()
* Conditional Logic (If)
* Variable Handling

## Input

Please use the following address to contact me [john.doe@localcompany.com](mailto:john.doe@localcompany.com) on the company email.

## Process

1. Locate the @ symbol.
2. Extract the username portion before @.
3. Extract the domain portion after @.
4. Reconstruct the email address.
5. Display the extracted email address.

## Output

The email address is [john.doe@localcompany.com](mailto:john.doe@localcompany.com).

## Skills Demonstrated

* String Processing
* UiPath Variables
* Conditional Statements
* Text Extraction
* Automation Logic
